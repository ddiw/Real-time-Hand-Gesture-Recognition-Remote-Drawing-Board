# MediaPipe 손 제스처 규칙 테스트

현재 단계는 전체 원격 그림판이 아니라 Container B의 21개 랜드마크 출력과
Container C의 규칙 기반 명령 판정을 검증하는 최소 프로토타입입니다.

## 실행

```powershell
python -m pip install -r requirements.txt
.\download_model.ps1
python app.py
```

카메라가 여러 개인 경우 `python app.py --camera 1`처럼 번호를 바꿉니다.
종료는 `Q` 또는 `Esc`입니다.

창의 `CAPTURE` 버튼을 클릭하거나 스페이스바를 누르면 `captures/` 폴더에
다음 두 파일이 함께 저장됩니다.

- 화면에 판정 결과가 표시된 JPG 이미지
- 21개 `(x, y, z)` 좌표와 각도, 거리 비율, 판정 결과가 포함된 JSON

저장 위치는 `python app.py --output 내폴더`처럼 변경할 수 있습니다.

## 현재 명령 규칙

손가락 펴짐 판정에는 MediaPipe의 3D 월드 좌표를 씁니다. 검지가 카메라를 향해도
2D 투영으로 거리 값이 무너지는 문제를 줄이기 위해서입니다. 반면 좌우 이동은
손 중심 기준인 월드 좌표로는 감지되지 않으므로 화면 정규화 좌표를 씁니다.

- 검지·중지·약지·새끼 PIP 각도가 각각 120도 이상이면 해당 손가락 펴짐
- 각 손가락 상태는 최근 5프레임 중 4프레임 이상 유지돼야 확정
- 손가락은 검지 → 중지 → 약지 → 새끼 순서로만 셉니다. 엄지는 세지 않습니다.

| 자세 | 명령 |
| --- | --- |
| 주먹 (0개) | `CLEAR` — 그림과 배율을 초기화, 주먹 한 번당 한 번 |
| 1개 | `DRAW` |
| 2개 | `ERASE` |
| 3개 + 좌로 이동 | `ZOOM_IN` |
| 3개 + 우로 이동 | `ZOOM_OUT` |
| 그 외 | `IDLE` |

모드 락이 없으므로 자세를 바꾸면 곧바로 명령이 바뀝니다.

확대·축소 감도는 손 크기와 카메라 거리에 좌우되지 않도록
`손바닥 중심 x / 화면상 손바닥 너비`로 계산합니다. 이 값이 기준점 대비 `0.12`
손바닥 폭만큼 움직일 때마다 줌 이벤트 하나가 발생하고 기준점이 옮겨갑니다.
손을 멈추면 줌도 멈춥니다. 감도는 `ZOOM_MOTION_RATIO`로 조정합니다.
